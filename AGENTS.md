# BOOKLY — repo-specific guidance

Fully client-side bookstore demo (Next 16.3.1 + React 19.2 + Tailwind v4 + BoldKit neubrutalism). No backend, no images — covers, avatars, and backgrounds are all generated (SVG/canvas). Auth/cart/wishlist are localStorage stores. Demo account: `yousseif@bookly.demo` (any password).

## Commands

- `npm run dev` — Turbopack dev server (port 3000). No test suite exists.
- `npm run build` — build + typecheck; `npm run lint` — ESLint only.
- Lint is clean except 2 warnings in vendored BoldKit files (`ui/empty-state.tsx` alt-text, `ui/shapes.tsx` unused `filled` prop) — expected, do not "fix" them.

## Next 16 / React 19.2 quirks

- `params` / `searchParams` are async — `await` before use (see `app/product/[id]`, `app/products`).
- Modules using hooks that are imported by server components MUST have `'use client'`. BoldKit files often ship without it — patching the vendored file is the established fix (`ui/use-theme.tsx`, `ui/sonner.tsx`, `ui/canvas-effects/Topography.tsx`).
- Hydration-safe stores: `src/providers/store-providers.tsx` wraps `useSyncExternalStore` with a true `getServerSnapshot` (SSR-time initial value). Any new localStorage store must follow this pattern — passing `getSnapshot` as the server snapshot caused cart-badge hydration mismatches. Storage keys: `bookly-theme`, `bookly-cart`, `bookly-cart-open`, `bookly-session`, `bookly-users`, `bookly-wishlist`.

## BoldKit components

- Install with `npx shadcn@latest add "https://boldkit.dev/r/<name>.json" --yes --overwrite` → lands in `src/components/ui/`. Check `boldkit.dev` registry via MCP tools before hand-rolling components.
- `src/components/decor/` is the hand-rolled layer (blobs, arrows, typography canvas, illustrations, avatar, reveal) — all decor must be `aria-hidden` + `pointer-events-none`, transforms/opacity only.
- `ui/canvas-effects/Topography.tsx` is theme-aware: white canvas in light mode, opaque `#0a0e17` in dark (reads the `dark` class on `<html>`); optional `background` prop overrides. It paints an opaque field — never use it as a subtle overlay without opacity control.

## Dev-server gotchas

- Turbopack HMR panics (`Cell ... EcmascriptMergedChunkVersion ... no longer exists in task ... Turbopack Panic`) can loop forever after a "Fast Refresh full reload" (e.g. editing `store-providers.tsx` while dev runs). Fix: kill the dev server, `rm -rf .next`, restart. A stale server also holds port 3000 (`kill` it or dev falls back to 3001).
- `AGENTS.md` block above is regenerated by `next dev`; leave it in commits.
- `src/app/globals.css` is the actual CSS entry (imported in `layout.tsx`); `src/styles/` holds extra styles (BoldKit theme). `CLAUDE.md` just references `@AGENTS.md`.
- `@multiavatar/multiavatar` is CJS default export without types — `src/types/multiavatar.d.ts` declares it; returns a full `<svg>` string, seed drives pattern only (never embed the seed as text).
